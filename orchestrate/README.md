# watsonx Orchestrate tools for the dashboard

> **Building the wxO agent?** See [`AGENT_SETUP.md`](AGENT_SETUP.md) for the
> paste-ready agent behavior and the `knowledge/` upload files (generated by
> `build_knowledge.py` from `pipeline/data/`).

Give the site's embedded Orchestrate assistant (the `wxOConfiguration` chat in
`index.html`) real skills over the dashboard data: 15 tools covering
financials, segments, FCF, M&A, macro series, regressions, and a live quote.

## How it works

`agent/server.py` exposes every dashboard tool as a plain REST endpoint
(`POST /tools/{name}` — no LLM in the loop), and this folder's
[`openapi.json`](openapi.json) describes them so Orchestrate can import the
whole set at once.

## Import steps

1. Start the tool server where Orchestrate can reach it:
   `pip install -r agent/requirements.txt && python agent/server.py`
   (for a cloud Orchestrate instance, host it somewhere public and change the
   `servers[0].url` in `openapi.json` accordingly).
2. In watsonx Orchestrate: **Agent Builder → your agent → Toolset → Add tools →
   Import from OpenAPI** and upload `orchestrate/openapi.json`.
3. Add the imported tools to the agent behind the site embed, and instruct it:
   *"Use these tools to answer questions about IBM's historical financials,
   M&A record, and macro context. Always cite the years used."*

The live server also publishes its own always-current spec at
`http://localhost:8787/openapi.json` (includes `/chat`, which lets Orchestrate
delegate a whole question to the local CUGA agent as a single tool call).

## In-browser alternative

For agents that can execute JavaScript in the page (e.g. CUGA's browser mode),
`window.CUGA` (from `agent-tools.js`) offers the same data tools plus page
actions — switching tabs, configuring the Regression Lab, opening M&A era
drawers. `window.CUGA.manifest()` describes every tool.
